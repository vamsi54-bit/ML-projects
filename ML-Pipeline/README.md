# ⚙️ Machine Learning Pipeline

An end-to-end machine learning pipeline for preprocessing, training, and evaluating a model using Python.

---

## 📌 Objective

To build a structured workflow for:

* Data preprocessing
* Feature scaling
* Model training
* Model evaluation

---

## ⚙️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn

---

## 🧠 Pipeline Workflow

1. Load dataset
2. Preprocess data
3. Apply scaling
4. Train model
5. Evaluate performance
